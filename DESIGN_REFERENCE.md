# Mobile design direction

Visual reference: the [official ChatGPT iPhone App Store listing](https://apps.apple.com/us/app/chatgpt/id6448311069), checked on 2026-10-16, plus the request to make this Codex interface feel similarly calm and readable on a phone. Use the reference for layout rhythm and touch behavior; use an original Codex Mobile identity and icons.

- Keep the conversation as the main surface, with a compact title/header above and a persistent rounded composer above the keyboard and safe area.
- Put thread history in a slide-out drawer; use native sheets for settings, workspace selection, activity, and decisions that need the user's attention.
- Use neutral backgrounds, generous message spacing, legible code blocks, distinct user and agent treatment, and restrained accent color for focus and state.
- Offer system light/dark appearance and high-contrast working, input-needed, offline, and error states; avoid depending on color alone.
- Keep frequently used actions reachable with one thumb: new thread, attach, send, stop, and approval decisions.
- Carry over the web UI's information and interactions while adapting controls to touch targets, safe areas, and on-screen keyboards.
